# Banking Risk Analytics Project

## Project Overview

This project focuses on **end-to-end banking risk analytics** to identify customer loan risk profiles and support data-driven credit decisions. Using **Excel, Python, SQL, and Power BI**, the project analyzes customer data to uncover risk factors, understand default patterns, and provide actionable insights for financial institutions.

The analysis helps banks **reduce loan default risk, optimize credit approvals, and improve risk management strategies**.

---

## Objectives

* Identify key **risk factors** influencing loan defaults across customer segments
* Analyze customer behavior based on **income, credit score, and repayment patterns**
* Generate **actionable insights** to improve credit scoring and approval decisions
* Support **risk mitigation strategies** to minimize financial losses

---

## Dataset Description

The dataset includes structured banking and loan-related data such as:

* Customer demographic information
* Income and employment details
* Credit score and loan attributes
* Repayment and default indicators

Data was initially available in **Excel format** and processed across multiple tools for validation and analysis.

---

## Data Cleaning & Preparation

* Handled **missing values** using appropriate imputation techniques
* Removed **duplicate records** and validated data integrity
* Standardized data types and corrected inconsistencies
* Detected and treated **outliers** to improve analytical accuracy
* Verified data quality using defined validation rules

Tools Used: **Python (Pandas), Excel**

---

## Exploratory Data Analysis (EDA)

* Performed **statistical analysis** to calculate summary statistics and correlations
* Analyzed relationships between **income, credit score, and default status**
* Identified trends and patterns using **data visualizations**
* Segmented customers into **income-based risk groups** (High, Middle, Low)

Visualization Tools: **Matplotlib, Excel charts**

---

## Customer Segmentation & Risk Analysis

Customers were segmented into earning groups:

* **High-Income Segment**: Risk linked to investments and volatile assets
* **Middle-Income Segment**: Risk influenced by job stability and expense patterns
* **Low-Income Segment**: Higher exposure to debt burden and limited credit access

This segmentation enabled **targeted risk assessment and mitigation strategies**.
